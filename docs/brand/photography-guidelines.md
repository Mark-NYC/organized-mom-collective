# Organized Mom Collective Photography Library

Created October 12, 2026. **Pilot in progress. Nothing in the candidate catalog is cleared for publication.**

## Brand target
Real family routines and imperfect everyday home moments. Warm natural daylight, muted whisper tones, ordinary lived-in homes, human faces where rights allow. Avoid synthetic-looking families, polished white kitchens, staged smiles, and heavy HDR.

## Workflow
1. Source photographs from primary photo pages and identify a photographer. Favor cohesive series from the same photographer.
2. Review original visually. Check metadata and creator statements before calling an image human-photographed. If uncertain, exclude.
3. Record original photo URL, creator, license URL, date checked, and whether attribution is mandatory. Keep the record internally.
4. Determine release status. Unknown is **not** permission. Flag any identifiable people, especially children.
5. Approve usage channels separately: editorial web, sales pages, ads, Pinterest. Only use in contexts where rights are adequate. Never imply that pictured families bought or endorse our calendar.
6. Download original assets only via permitted downloads. Preserve originals outside the deployed site. Create optimized WebP versions only for approved assets.
7. Create a numbered contact sheet for human visual selection; record which photos pass.
8. Do not publish or deploy the library without review.
