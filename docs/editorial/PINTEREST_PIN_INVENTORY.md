## Append fields to each newly confirmed pin
- Unique ID / final image filename
- Article title, exact URL, article source path / evidence
- Hook, visual subject/action, composition, search-curiosity-save job
- Pinterest title, description, image-accurate alt text, actual board
- State: idea / generated / approved / scheduled / published / rejected
- Scheduled/published date and actual Pinterest Pin URL, if confirmed
- Notes on revision and duplicate checks
- Metrics with measurement date when available

Keep a pin distinct in **meaning**, not merely a color swap or a rephrased title. Avoid republishing the same image as a newly invented concept.
