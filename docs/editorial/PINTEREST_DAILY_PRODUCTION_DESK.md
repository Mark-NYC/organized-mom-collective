# Daily Pinterest production desk

**Primary invocation:** "What 10 pins do we need to make today?" This file is the operating contract for ChatGPT, Claude, or another assistant using the GitHub repository. Use live date, not the original spreadsheet date. The assistant must return actual actionable work, including complete stand-alone Gemini prompts, not a generic strategy recap.

## Business outcome and creative allocation

- Goal: test Pinterest as an acquisition channel toward **100 Organized Family Club sign-ups in the next 12 months** (a working objective, not a performance claim). Distinguish free-trial enrollments, conversion to paid, and retained paid members. Optimize qualified traffic and enrollments; do not optimize only impressions.
- **Rolling 100 new Pin creatives** target: 30 lifestyle inspiration, 30 editorial pain/value cards, 25 search-first guides/free generators, 15 verified Club product demonstrations. This is a 90-day hypothesis, **not** a Pinterest algorithm rule. Measure all lanes and change the allocation only with dated evidence.
- Count against a rolling window of **new creative**, not calendar days. Don't force 3 lifestyle images into every 10-pin day, because inspiration galleries are created in large batches and scheduled across days/weeks. On non-gallery production days fill with editorial/search/product prompts; keep the rolling mix visible.
- Keep the separate **6/3/1 research mix** (six observed search patterns, three audience-specific situations, one creative experiment) as a *different classification*. Research evidence is not implied by a keyword label.
- Preserve approved creatives, permanent 500-pin IDs, OMC-V inspiration IDs, historical proposed schedules, and existing bulk CSVs. No silent replacement, renumbering, double-counting, or claims of Pinterest publication without account evidence.

## Morning decision order

1. **Inventory first**: read this file, SEASONAL_ACQUISITION_PLAN.md, PINTEREST_STRATEGY.md, PINTEREST_RESEARCH_LOOP.md, IMAGE_FIRST_PINTEREST_WORKFLOW.md, PINTEREST_CREATIVE_DIRECTION.md, PINTEREST_BOARDS.md, MASTER_TRACKER_README.md and current CSVs, reconciliation, generated asset folders, approved batches, and current live site pages. Determine which pins are already created, scheduled, published, held, or merely proposed. If Pinterest account status is inaccessible, state that and do not guess.
2. **Seasonality second**: work backward from the *family's need*, ideally research and prepare 90–120 days prior and start Pinterest distribution 60–90 days prior. Check actual month/kit and Club print cutoff against current site/source; never promise impossible mailing dates. If a seasonal opportunity is late, say so and choose the best remaining action.
3. **Content gap third**: ask whether a current, relevant landing page already satisfies the pin. If not, recommend a new search-driven guide/free tool landing page or a lifestyle gallery **as a separate prerequisite work package**, not ten pins pointing to a nonexistent URL.
4. **Gallery trigger**: periodically (hypothesis: every 2–3 weeks, adjusted for publish backlog, search seasonality and measured demand), assess whether a new visually searchable home-organization gallery is due. Prefer a coherent **39 original article photos + 10 extra independent promotional Pins = 49 Gemini image prompts**, using the established long-gallery precedent. The 39 photos become the on-site gallery and may support additional image-first Pinterest Pins after publishing. The 10 extras are distinct Pinterest-ready promotional creative. Do **not** mistake 49 images for 49 immediately scheduled pins, or a fixed daily 3/10 lifestyle quota. Some older galleries use 15 images; use 39+10 for a new approved premium-gallery project unless evidence calls for smaller scope.
5. **Select the day's work**: ordinarily ten independent ready-to-generate prompts, excluding approved/scheduled assets. If a gallery is due, the day's deliverable is an explicit **gallery production sprint** with 49 prompts (or a reasonable numbered first tranche if asked for ten), its needed article route/content plan, filename convention and publishing lead time. Label it as a sprint, and show how the rolling mix will be balanced later. Never generate a fake finished article or fake published gallery.
6. **Quality gate**: choose substantive hooks and distinct compositions from actual articles, kits and tools. No repetitive color swaps. For product Pins use actual supplied/source print artwork or verified screenshots as an insert, not an AI reconstruction. A Gemini image prompt can produce the background; accurate print artwork and typography may need controlled compositing afterward.
7. **Status & follow-through**: return the next action, target destination, draft filename, and intended board for each. After the owner supplies completed images, QA; then update manifests and generate Pinterest bulk CSV with verified URLs and sensible publication dates. Do not call a CSV scheduled until Pinterest confirms import.

## Required response to "What 10 pins do we need to make today?"

Start with **today's recommendation**: whether it is a normal ten-pin day, a 49-image lifestyle gallery sprint, a new seasonal article/landing-page prerequisite, or a mixed workday. State the reason: season of need, current gaps, rolling mix and already-produced inventory. If the newest GitHub state or Pinterest account cannot be verified, explicitly identify the gap and offer best-effort recommendations based on available evidence.

For each normal pin, provide:
- **# / lane / working Pin ID** (existing exact OMC-P ID when available; otherwise `new ID pending allocation`; never invent permanent IDs), **filename** (lowercase kebab-case, unique), **season/need date**, and recommended first-post window;
- **verified landing URL** (or `blocked: build page first`), actual board name from registry, a real specific customer action, and a short reason this angle deserves a slot;
- **complete copy/paste Gemini prompt**, self-contained: art direction, visual scene, exact visible text, accurate product instructions, 2:3 portrait 1000×1500, typography **Georgia headline / Montserrat body and labels**, and the **complete hex palette**:
  - Charcoal `#545454`
  - Warm Ivory `#FBF7F1`
  - Soft Frost Blue `#CDDDE1`
  - Soft Leaf Green `#D4DFC4`
  - Pale Apricot `#F1D8A8`
  - Powder Blush `#E8D2D6`
  - Warm Mushroom `#D5C5B8`
  - Soft Clay `#D8B79F`
  - Pale Evergreen `#BBCBC4`
  Specify 1–2 of these as primary accents for each visual and preserve mobile legibility. Never expect Gemini to remember colors or fonts from another prompt.
- Every prompt explicitly excludes visible generated faces, illegible or invented writing, fake OMC charts/products and text duplication. If using a real personalized monthly kit, describe an **approved actual source image to composite**, with legible correct names/ages/steps; do not tell Gemini to invent the sheet. Show **pain → actual solution → credible relief**, without promising a tool magically changes behavior.

For each gallery sprint provide:
- **Working topic + Pinterest search evidence status + target season + first publishing window**; explain why a new article beats an existing gallery.
- **49 numbered, fully independent Gemini prompts with final filenames** and brief scene differentiation: images 01–39 are original article/gallery photography with unique stop-scroll characteristics and no promotional overlay; images 40–49 are independent premium Pinterest promotional creatives with keyword/benefit overlay where appropriate.
- All 49 prompts repeat required **hex colors, Georgia and Montserrat, format, no faces, distinct scene/angle, physical plausibility**. For gallery photography typography is **not placed in the image**, but the project design system still uses Georgia and Montserrat for article headings and Pinterest text layers. Do not force brand-color furniture into every realistic room.
- Specify gallery data/source path, 39 distinct useful idea headings and section categories, article outline, image-specific `#idea-N` links, matching Pin metadata plan and actual verified board. Record 10 extras independently; prevent duplication with the 39 article images.
- Make the *gallery article* genuinely helpful: meaningful descriptions and family-use advice, not 39 keyword-stuffed captions. Recommend a related free tool and a contextual optional Club path, never an unrelated forced upsell.
- If 49 full prompts are too large for one response, return the production plan plus a clearly labeled first numbered tranche and note that the remainder has **not** been delivered. Do not claim 49 prompts were provided.

## Topic-selection rubric

Choose the next gallery or seasonal guide based on, in order: (1) need date and 60–90 day lead time; (2) actual keyword/reference evidence; (3) clear family-oriented relevance; (4) existing article/photo saturation; (5) a credible on-site next action; (6) distinctive visual potential. For galleries, pantry/closet/mudroom/toy-storage/lighting have already been explored: avoid creating close duplicates unless evidence justifies a more focused style subcategory. A decor-only topic can draw inspiration traffic but should not crowd out high-intent needs.

## Scoreboard and review cadence

Use actual Pinterest and web analytics when available: new pins by lane (rolling last 100), Pin age, saves per impression, outbound clicks/CTR, engaged site sessions, free-tool starts/completions, opt-in leads (with consent), Club checkout starts, free-trial enrollments, paid conversions and retained members, plus calendar purchases. Segment by *lane + topic + destination + publish cohort*. **No attribution guesses**: if UTM or conversion tracking is not in place, mark unknown. Every 30 days diagnose; at 60 days compare matured cohorts; at 90 days reallocate new production toward outcomes. Maintain the 100-signup goal as a scoreboard, not a claim that 100 will occur.

## Prompts to recognize

- "Is it time for another lifestyle article?" → inventory, seasonality, recommended topic and a 39+10 gallery sprint plan.
- "Give me the 49 Gemini prompts for the next gallery" → the complete 49-image production specification; no generic suggestions.
- "The images are uploaded; make the CSV" → verify actual files, site image URLs, board, link anchors, metadata and scheduling; write an import-ready CSV only if requirements are met.
- "What should we make next month?" → rolling seasonal campaigns, article gaps, galleries, Club product creatives, and realistic capacity.

## CSV creation and reconciliation rule (mandatory, 2026-10-31)

When the owner says "make the CSV," verify image filenames/URLs, boards, links and the requested publication schedule, then group pins into **separate import CSVs with only one occurrence of each normalized destination `Link` per file**. Multiple pins may target the same landing page, but must be placed in different uploads. Preserve *all* rows and their exact planned dates; never omit a pin to get a valid CSV. Validate distinct media URLs and pin IDs too. Flag any file needing a separate import. This is the tested OMC workaround for Pinterest `Duplicate Pin link` errors (three rejected rows from an eight-pin CSV subsequently uploaded successfully in a separate CSV on Oct 31, 2026), not a universal Pinterest guarantee.

Track `prepared` / `submitted` / `confirmed` / `rejected` / `published` per permanent pin ID, batch and CSV filename. Importing a CSV does **not** prove every row was scheduled. Reconcile against Pinterest processing emails and the visible queue. Produce a recovery CSV only for pins confirmed rejected/missing, after checking for existing scheduled pins. Do not modify the real destination URLs or falsely claim that the import succeeded.
