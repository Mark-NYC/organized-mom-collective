# March chore chart icons

Artwork for the March family chore charts (`/app/club/march`). The mapping from chores to icons is in
`src/data/club/march-chore-icons.ts`; add a file here with one of the names below and the charts use it on the next
build, no code change.

- Format: lossless WebP, transparent background, square canvas, art centered with even padding, no background circle.
- The chart sizes every icon by its slot (`object-fit: contain`), so any square size works; 256 × 256 px or larger
  prints sharply.
- Until a file is here, the chore shows its responsibility-library illustration if it has one, otherwise no picture.
